# Aurum – Luxury Footwear Landing Page

Aurum is a high-end, responsive landing page crafted for a luxury shoe brand. Built with modern web tools, it focuses on clean visual hierarchy, fast load performance, and a smooth user experience to showcase premium products effectively.

---

## Features

* **Responsive Layout:** Works seamlessly across desktop, tablet, and mobile devices.
* **Fast Performance:** Optimized rendering using Next.js App Router for quick page transitions.
* **Modern UI:** Styled with Tailwind CSS to maintain a sleek, clean, and elegant presentation.
* **Product Showcase:** Designed sections highlighting key products, brand story, and clear call-to-actions.

---

## Tech Stack

* **Framework:** Next.js
* **Library:** React
* **Styling:** Tailwind CSS
* **Deployment:** Vercel

---

## Local Development

If you'd like to run this project locally on your machine, follow these steps:

1. Clone the repository:
   git clone https://github.com/Tareefkhan-web/luxury-shoe-landing-page.git

2. Go to the project directory:
   cd luxury-shoe-landing-page

3. Install required packages:
   npm install

4. Start the local server:
   npm run dev

Now open http://localhost:3000 in your browser to view the site.
